# Changelog

## v1 — First Stable Release

First public stable release of WOS Gift Redeemer.

### Included
- Fetch active WOS gift codes.
- Redeem codes for selected accounts.
- Saved-code catalog and selective redemption.
- Run-based redemption history.
- Retry-safe handling for connection failures.
- Classic Retro and Modern themes.
- System, Light, and Dark appearance modes.
- Automatic 30-day data cleanup.
- Responsive Android interface.
